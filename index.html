04 Problem-Solving

Practice scenarios connected to my current skills in basic networking, Windows installation, computer maintenance, software support, and Office applications. These are troubleshooting examples, not claims of completed client cases.

Case 1 — Laptop cannot connect to Wi-Fi
Related skill
Basic networking and Wi-Fi troubleshooting
Possible causes
Wi-Fi is turned off, airplane mode is on, the device is not connected to the right network, or the router has a connection issue.
Diagnostic steps
Check airplane mode and Wi-Fi; confirm the network name and password; see whether another device can connect; restart the laptop and, if appropriate, the router.
Safe next step
If other devices also cannot connect, report the router or internet connection issue to the network owner. If only this laptop is affected, ask for help checking its network settings or adapter.
Lesson
Check the simplest causes first and compare with another device before changing network settings.
Case 2 — Preparing a PC for Windows installation
Related skill
Windows 10/11 installation and computer maintenance
Possible causes
The PC may not meet installation requirements, important files may not be backed up, or installation media may be missing.
Diagnostic steps
Confirm the device and Windows version; check hardware requirements; identify files that need backup; confirm approved installation media and a valid license.
Safe next step
Do not format or reinstall until the owner approves and important files are backed up. Ask a supervisor for guidance if unsure about the device, license, or installation method.
Lesson
Preparation, authorization, and data backup come before installation.
Case 3 — An application will not open
Related skill
Software support and application installation
Possible causes
The application may need an update, may not have installed correctly, or the computer may need to restart.
Diagnostic steps
Note the error message; check whether other applications open; restart the computer if appropriate; verify the application is from an approved source and check for updates.
Safe next step
Use the application's normal update or repair option. Before reinstalling, confirm the user has saved work and that the installer is approved.
Lesson
Record the message and try low-risk checks before changing or reinstalling software.
Case 4 — Laptop seems slow or is getting warm
Related skill
Basic computer maintenance and troubleshooting
Possible causes
Many applications may be running, vents may be blocked, or the device may need attention from a qualified technician.
Diagnostic steps
Ask when the issue started; check whether unnecessary applications are open; make sure the laptop is on a hard, flat surface and vents are not covered.
Safe next step
Save work and close applications the user does not need. Do not open the laptop or attempt internal repairs; escalate persistent overheating, unusual noises, or shutdowns.
Lesson
Basic external checks are appropriate for my current level; hardware repairs should be handled by a qualified technician.
Case 5 — A document or spreadsheet does not display as expected
Related skill
Microsoft Word, Excel, and PowerPoint basics
Possible causes
The wrong file may be open, the document may have unsaved changes, or formatting or zoom settings may have changed.
Diagnostic steps
Confirm the file name; check whether the document is saved; review zoom and page or cell formatting; compare with a known-good copy if available.
Safe next step
Save a separate copy before changing formatting. If the file will not open or appears damaged, preserve the original and ask for help rather than overwriting it.
Lesson
Protect the original file and verify changes before considering the issue resolved.

05 Employability

How my current technical skills connect to the entry-level IT Support roles I am preparing for.

Role I am preparing for

Entry-level IT Support, Help Desk, or Computer Technician Trainee. I can assist with basic computer setup, Windows installation, application installation and updates, and common laptop or Wi-Fi troubleshooting.

How I approach support issues

  1. Ask the user what happened and when it started.
  2. Check basic hardware, power, settings, and network connections.
  3. Try a safe, relevant troubleshooting step, such as checking Wi-Fi or restarting an application.
  4. Confirm whether the issue is resolved and explain the next step clearly.
  5. Ask for help or escalate when the issue is beyond my current skills.

First year on the job

Long-term growth

Build on hands-on support experience to handle a wider range of hardware, Windows, application, and network issues with increasing independence.

10 Reflection

500–800 words.

Before BSIT, I only knew how to use a computer for school work. I took TVL-ICT in senior high school, so I knew a little about computer parts.

In BSIT, I learned how to fix simple computer problems, how the internet and Wi-Fi work, and how to install Windows. I also learned how to make a simple website. The most important thing I learned is to fix a problem step by step and not to panic.

The project that taught me the most was this portfolio website. I learned how to organize my work and show my skills. The hardest part for me was fixing errors when something did not work. I learned to be patient and try again.

My skills have improved, but I am still a beginner. I want to get better at networking and at repairing computers. I also want to be more confident when helping other people with their computer problems.

I want to become a good IT Support staff who is helpful, patient, and reliable. I am ready to start my career because I have the basic skills and I am willing to keep learning.
